Fases recomendadas

📦 Fase 1 — Capa de abstracción (semana 1)
Crear archivo back/forum/game/config/universo.php con constantes:
UNIVERSE_SLUG, CURRENCY_NAME, FACTIONS (array), REGIONS (array),
POWER_TYPES (array), POWER_TABLE, INNER_POWER_TYPES (array), INNER_POWER_TABLE,
RACES (array), CARD_TYPES (array), STYLES (array).
Objetivo: Todo el código lee de constantes, no de strings hardcodeados.
🔧 Fase 2 — DB y helpers (semana 2)
- Renombrar tablas: game_akuma_no_mi → game_powers, game_haki_progress → game_inner_power
- Cambiar ENUMs a VARCHAR con valores desde config
- Renombrar columnas: akuma_fruit_id → power_id, berries → currency, sea_zone → region
- Renombrar archivos helper y funciones
🎨 Fase 3 — CSS + JS + vistas (semana 3)
- Renombrar variables CSS: --color-mugi → --color-primary, colores Straw Hat → paleta genérica
- Renombrar clases: .rpg-akuma-* → .rpg-power-*, .rpg-card--haki-* → .rpg-card--inner-power-*
- Renombrar funciones JS
- Actualizar vistas PHP con textos desde config
📝 Fase 4 — Datos y contenido (semana 4)
- Reescribir linaje_catalog.json y linaje_system.json con razas del nuevo universo
- Reescribir seed data (islas, NPCs, oráculos, misiones)
- Actualizar o reemplazar lore.json
- Regenerar Default-theme.xml desde el CSS actualizado
🧪 Fase 5 — Testing y ajustes (semana 5)
- Probar que el sistema funciona sin referencias a OP
- Configurar universo.php para HxH (o el que elijas)
- Ejecutar migraciones SQL
- Smoke test: ping, personajes, cartas, navegación, tienda
- Actualizar documentación y guías

🎯 Objetivo final

Un sistema donde cambiar de universo sea editar un archivo universo.php + reemplazar seed data + reemplazar lore. Sin tocar lógica del sistema.

El código nunca menciona "Akuma", "Haki", "Marine", "Pirata", "Berries", "Grand Line". Todo viene de configuración.
