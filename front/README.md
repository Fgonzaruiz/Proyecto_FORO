## `front/` — Autoría de tema y plantillas (no runtime)

Aquí se editan:
- export/import del tema (XML)
- plantillas grandes (HTML) antes de copiarlas al ACP (o sincronizarlas)
- assets de diseño si quieres versionarlos fuera del runtime

### Estructura propuesta

```
front/
  theme/
    theme.xml
  templates/
    mybb/
    game/
    admincp/
  ficha/
    parts/
    INSTRUCCIONES_MyBB.txt
```
