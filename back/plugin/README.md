## `back/plugin/` — Fuente de plugins MyBB (empaquetable)

Aquí versionas el código de plugins que luego se copian/instalan en:
- `back/forum/inc/plugins/`

Recomendación:
- un plugin “puente” que emita eventos MyBB → backend mecánicas
- plugins pequeños adicionales si hace falta (p.ej. helpers de templates)
